## Proyecto destacado

### SistemaStock
Sistema de stock desarrollado en C# (consola) para la gestión de productos y ventas.

Funcionalidades principales:
- Alta de productos (nombre, precio y stock)
- Visualización de productos
- Registro de ventas con actualización automática del stock
- Validación de datos para evitar errores

Repositorio: https://github.com/balarcon-dev/SistemaStock
